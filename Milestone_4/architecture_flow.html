Complete Pipeline & Knowledge Base Architecture

Detailed mapping from multi-platform ingestion to Gemini LLM synthesis and ChromaDB grounded RAG.

Architecture Spec v4.2 • Milestone 3 & 4 Continuous Integration

📹 Ingestion Pipeline

Unified multi-source meeting intake supporting synchronous and asynchronous ingestion:

  • Local Upload: MP4, MP3, WAV, M4A with FFmpeg extraction.
  • Zoom Cloud: OAuth 2.0, Webhook verification with SHA256 HMAC CRC token validation.
  • Google Meet: Google Drive API polling with MD5 duplicate suppression.

✨ Dual-Engine AI Synthesis

Robust intelligence extraction with zero downtime failover strategy:

  • Gemini Primary: Generates executive summaries, action items, deadlines, assignees, and key decisions.
  • Fallback Engine: OpenAI / Local Heuristics triggered on quota depletion or network timeout.
  • Schema Enforcement: Strict Pydantic JSON contracts.

🔮 Knowledge Base & RAG

Sub-second semantic intelligence matching the user's workflow:

  • SQLite Metadata DB: Stores normalized meeting records, users, and audit trails.
  • Embeddings: all-MiniLM-L6-v2 384-dimensional normalized vectors.
  • ChromaDB: Persistent cosine similarity vector store with metadata filtering.
  • Grounded RAG: Gemini RAG synthesis with strict citation tracking [Source: Meeting #ID, Timestamp].

📑 Reports & Security Layer

Enterprise deliverables and strict access control boundaries:

  • Executive PDF: ReportLab high-fidelity PDF with cover, metadata, and action item tables.
  • Tabular CSV: RFC-4180 compliant relational exports.
  • Access Control: Multi-tenant isolation with Bcrypt password hashing.
